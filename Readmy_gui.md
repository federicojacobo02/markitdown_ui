## Desktop GUI (Windows)

This branch adds a native, dark-mode Windows desktop interface built with Tkinter, allowing you to convert documents to Markdown without using the command line.

### Quick Start:
1. Clone or download this branch (`feature/gui`).
2. Double-click on **`Start_MarkItDown.bat`** (or run `python gui.py` from your terminal).
3. On the first run, required dependencies will be installed automatically and the application window will launch.
